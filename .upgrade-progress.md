## 2026-06-12 — Final-review fix: guard second stderr-noise-filter call site

**Root cause (corrected):** Earlier runs attributed "mass capture teardown errors"
(OSError: [Errno 29] Illegal seek) to pre-existing upstream baseline noise. That was
wrong. The actual cause: `hermes_logging.py` has TWO `_install_macos_stderr_noise_filter()`
call sites. The import-time site (~line 242) was correctly guarded with
`if "pytest" not in sys.modules:`, but the second call site inside `setup_logging()`
(~line 345) was UNGUARDED.

v0.16 added an autouse fixture (`tests/hermes_cli/conftest.py:41`) that imports
`hermes_cli.main` during test setup. `hermes_cli/main.py:443` calls `setup_logging()`
at import time → the unguarded call ran and dup2'd a pipe over pytest's seekable
capture tmpfile fd → every subsequent capture snapshot raised OSError: Illegal seek.

**Fix:** Added the identical guard to the `setup_logging()` call site:

```python
# Skipped under pytest: guard matches the import-time call site above.
if "pytest" not in sys.modules:
    _install_macos_stderr_noise_filter()
```
